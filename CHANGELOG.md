# Changelog

## 0.2.0

- Added Human Manager team selection and human-controlled tactics.
- Added an AI Assistant Coach and autonomous opponent CoachAgent.
- Added validated read-only LLM tool calling for coaching decisions.
- Added Groq primary inference, Gemini fallback, deterministic fallback, and
  runtime provider status.
- Added in-memory provider usage tracking improvements.
- Added Management Mode, Match Center, responsive SVG match presentation, and
  presentation-only match lifecycle milestones.
- Added release-oriented design and scope documentation.

## 0.1.0

- Initial public release.
- Probabilistic two-team football match simulation.
- Groq-powered Coach Agents and Cognitive Footballers.
- Deterministic fallback logic.
- Timed browser match presentation.
- AI token and cost tracking.
- Reproducible calibration and testing.
